# أصل للتقييم العقاري — النسخة الجديدة

واجهة عربية بخط Cairo محفوظ محلياً، وصور فوتوغرافية، وأزرار دائرية، وحركة ظهور الشعار في كل صفحة.
تغطية الخدمات: جميع أنحاء المملكة العربية السعودية.

## التشغيل
ارفع محتويات هذا المجلد إلى جذر الاستضافة. للتجربة المحلية شغّل:
python3 -m http.server 8000
ثم افتح http://localhost:8000
لا تعتمد المعاينة على فتح ملفات HTML مباشرة، لأن روابط الموقع تبدأ من جذر الاستضافة.

## التحقق
فُحصت الصفحات الـ21 عند عرض 390 بكسل دون تمدد أفقي أو صور محلية مفقودة أو أخطاء JavaScript.
فُحصت الصفحة الرئيسية أيضاً عند عرض 1440 بكسل، وفتح نموذج الطلب وإغلاقه وقائمة الجوال.
لم يُرسل طلب حقيقي ولم يُختبر تسليم البريد أو خدمات الخريطة الخارجية.
تُراعى إعدادات تقليل الحركة. تظهر حركة الشعار لمدة نحو ثانيتين ولا تعيق الضغط على الصفحة.
صور معاينة الكمبيوتر والجوال في preview.
